# 🩺 Prescripto – Doctor Appointment Booking System

A full-stack MERN application that allows patients to book doctor appointments online with secure authentication, online payments, and separate dashboards for Users, Doctors, and Admins.

---

## 🚀 Live Demo

🌐 Frontend: https://prescripto-frontend-gwag.onrender.com  
🌐 Admin Panel: https://prescripto-admin-kfgz.onrender.com

---

# 📌 Features

## 👨‍⚕️ Patient Features

- User Registration & Login
- JWT Authentication
- Browse Doctors by Specialization
- Book Appointments
- Online Payment Integration
- View Appointment History
- Cancel Appointments
- Update User Profile
- Responsive UI

---

## 🩺 Doctor Features

- Doctor Dashboard
- Manage Appointments
- Mark Appointments as Completed
- Cancel Appointments
- Update Availability Status
- Manage Profile Information
- View Earnings & Analytics

---

## 🛠️ Admin Features

- Admin Authentication
- Add New Doctors
- Manage Doctors
- View All Appointments
- Dashboard Analytics
- Manage Users & Doctors

---
